# Vue 介面遷移與工作目錄整理

保留 Python API、資料格式、隱私與地圖供應商。以 Vue 元件取代剩餘畫面產生器；既有服務負責網路、權限及第三方地圖生命週期。沿用 CSP 與既有視覺設計，分批驗證，不部署正式網站。

1. 個人檔案：基本資料、編輯、展示牆、內容管理及圖片裁切。
2. 工作區：任務卡、評價、情報點、小隊及成員。
3. 視窗：建立／加入、帳號／設定、遠征隊管理、審核、邀請、News。
4. 地圖與外框：搜尋、篩選、長按、定位與方向浮窗、導覽與共用狀態。
5. 完整建置與瀏覽器回歸；檢查帳號隔離、CSP、觸控、鍵盤與亮暗色。
6. 掃描並提交、推送 vue-version。安全搬移工作樹至 F:/work_project/tamagoyaki_support_vue，複製必要本機設定及資料副本，驗證 Git、建置與獨立啟動。原正式服務繼續由原目錄執行。

每批的驗收：原有功能與 API 相同、畫面由 Vue 管理、測試無前端錯誤，不降低授權或定位限制。控制器需同步查詢剛繪製的表單時，使用 Vue render API 的同步邊界；表單草稿與焦點需在非刻意切換畫面時保留。

最終搬移不覆蓋現存目錄，不刪除原正式資料，不提交金鑰、SQLite、媒體或執行日誌。記錄新目錄的執行方式與未切換正式服務的狀態。
