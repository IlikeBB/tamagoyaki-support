# 玉子燒支援隊 · Tamagoyaki Support

手機優先的遠征會合網頁。Python FastAPI、SQLite，遠征隊頁面與聊天介面使用 Vue 3，其餘前端沿用原生 JavaScript；底圖支援 Google Maps 與自架 Leaflet 1.9.4。正式網址：https://tamagoyaki-support.modoubletw.com/

## 專案結構

- `backend/`：Python 後端、資料存取與啟動入口。
- `tests/`：Python 單元與整合測試。
- `static/`：網頁介面、樣式、圖示及地圖資源。
- `frontend/`：Vue 單檔元件、遠征隊頁面與 Vite 建置設定。
- `scripts/`：部署腳本與瀏覽器驗證工具。
- `assets/`：地圖原始素材。

`data/`、`.run-logs/`、`artifacts/` 與本機設定檔保留在專案根目錄，並由 Git 忽略。

## 使用方式

1. 按右上「登入」→「註冊帳號」，設定登入名稱、密碼與顯示暱稱；再開啟下方「遠征隊」頁面建立、加入活動遠征隊或輸入邀請碼。
2. 下方「遠征隊」開啟獨立頁面（`/#expeditions`），可在「我的遠征隊／加入遠征隊」查看、搜尋、切換會場、建立及加入隊伍；私人隊伍以邀請碼加入。已登入者可在加入前按「查看成員」，透過可捲動視窗查看整個遠征隊的頭貼、暱稱和人數，每次載入 50 人；不會因此加入隊伍，也不回傳座標、小隊分組或邀請碼。任務與好友頁面不再顯示目前遠征隊的情境區塊。

活動會場另提供「台灣」與「日本」，可建立或瀏覽未指定單一場館的遠征隊，個人檔案與管理列表顯示對應地區名稱。地圖可自由移動，可用定位與地點搜尋查看實際集合地點；地圖中心選單仍使用已核對座標的四個固定場館。

建立隊伍預設不指定活動日期；勾選「添加活動日期」才顯示日期欄位，勾選後必須填寫有效日期。未指定日期的公開隊伍持續列在該會場的隊伍列表，介面統一顯示「未指定日期」；有日期的隊伍仍依原本日期範圍驗證及列表過期規則處理。既有日期資料保留。API 可省略 `event_date` 或傳入 `null`／空字串，SQLite 與歷史紀錄以空字串儲存未指定日期。
3. 主動開啟「定位設定」並同意定位後，預設分享給已接受的好友與目前小隊；也可選本機、僅好友、僅小隊或僅任務接取者。一般遠征隊成員不會收到個別 GPS。切換會先撤回原本的分享；加入隊伍不會自動開啟 GPS。
4. 發布交換、懸賞、配布或求助任務時，先取得目前 GPS 位置。任務發布點只有發布者與目前接取者能取得；即時位置依定位設定的分享對象提供。切換為好友或本機模式時，接取者改用任務發布點。
5. 到「情報點」或「隊友」建立隊內情報，分享攤位、官店、洗手間或集合點。情報點的座標分享給同一遠征隊，與個人即時位置分開。臨時資訊可設到期時間，永久情報保留在該遠征隊。
6. 在「好友」輸入對方的帳號名稱送出邀請，由對方接受。好友關係不需要加入遠征隊或小隊；開啟「我的好友位置分享」後，已接受的好友可查看你的即時位置。可獨立關閉好友分享、取消／拒絕邀請或移除好友。

碰觸地圖左邊緣或按「地點」可勾選場館地標、追蹤作者、我留言過、我按讚過的地標，符合任一項即顯示。四項預設開啟，全取消則隱藏地標。場館地標控制幕張、K 橫、PIA、有明的固定標記，關閉不影響場館選單與地圖切換。留言或按讚會自動追蹤作者；收回讚或刪除留言不會取消作者追蹤。既有按讚、留言會在升級時補建追蹤。只篩選目前遠征隊中原本有權查看的地標，不授予其他隊伍權限；情報點列表保留瀏覽隊內全部地標的入口，點選尋找可暫時顯示該地標，關閉卡片後恢復篩選。篩選勾選依帳號儲存在目前瀏覽器。人物標記依伺服器授權同時顯示，不再提供人物篩選。

任務看板只顯示進行中的任務，已完成與已撤回的任務不顯示；完成紀錄仍保留在伺服器。地標刪除期間停用重複操作，成功後立即移除列表、地圖圖示與已選取的卡片；較早送出的同步回應不會還原已刪除的地標。網路失敗可重試，其他人已刪除的地標會清除本機殘留畫面。指南針與 GPS 更新保留地標卡片中的操作按鈕，避免點擊途中被重建。

「隊友」頁面只顯示「我的小隊」，包含目前小隊所有成員的頭貼、完整暱稱與在線／離線狀態。遠征隊頁面不提供「小隊組合」入口，伺服器不向其他成員回傳別支小隊或分組。成員可自行建立小隊；加入既有小隊僅限與其中一位目前成員互為好友的人，邀請碼與連結都在伺服器檢查好友資格。小隊成員可按暱稱／帳號搜尋已接受的好友並傳送聊天邀請，對方確認後才加入。每人在同一遠征隊中同時加入一個小隊，只有該小隊成員能查看邀請碼。離開小隊不會退出遠征隊；預設好友與目前小隊模式會跟隨目前分組，明確選用的僅小隊／任務模式會停止原有分享，求助定位維持原規則。

遠征隊建立者固定為團長，可透過「管理」中的「變更遠征隊名稱」修改隊名（1–60 個字），也能指派或取消多位副團長，以及移除其他成員。名稱會同步至遠征隊列表、群聊與個人檔案牆；邀請碼、場館、日期、成員與小隊資格保留。已退出的建立者仍可從自己建立的遠征隊管理入口修改名稱。副團長只能移除一般成員，不能指派權限、移除團長／其他副團長或刪除遠征隊。管理名單只提供頭貼、暱稱、角色與可執行操作，不顯示小隊分組或座標；權限在每次操作的資料庫交易中重新確認。移除成員會撤回其未完成任務、釋出已接任務、停止該遠征隊的求助分享並移除小隊資格；空小隊自動解散。原有個人紀錄保留，持有有效邀請碼仍可重新加入，重新加入不保留副團長身分。已退出的建立者仍可從「管理我建立的遠征隊」管理成員或刪除遠征隊。

好友關係於加入時重新確認；若已解除好友，或好友已離開該小隊且沒有其他目前成員與你互為好友，舊邀請也無法使用。已在小隊的成員不會因好友關係改變被自動移除。邀請訊息沿用聊天的每分鐘 60 則限制與同一筆重試識別碼去重；伺服器會在交易中檢查目前小隊與好友資格，清單不回傳座標。

最後一位成員離開小隊、改加入另一支小隊，或退出遠征隊後，空小隊會在同一筆交易中自動解散，原邀請碼與小隊邀請連結失效。伺服器啟動時也會清除既有空小隊，保留仍有成員的小隊及遠征隊。

地圖人物標記使用圓點、半透明圓形光暈與扇形方向。自己的青色光暈配黃色圓點，扇形隨已授權的手機絕對指南針旋轉；未取得朝向或 GPS 已超過 2 分鐘未更新時只顯示圓點。好友保留愛心，遠征隊成員保留人形圖示，任務目標使用暱稱首字；其他人的扇形表示從你的座標往對方的地理方位，不代表對方的手機朝向。旋轉只更新自己的扇形，不重建地圖標記。此樣式共用於 Google 地圖與備用地圖，紅色求助驚嘆號維持原樣。可以點擊人物，或以鍵盤 Enter／空白鍵開啟尋人功能。

右下角固定「尋找隊友」按鈕已移除；點擊地圖人物仍可開啟尋人小窗。地圖邊緣與尋人小窗提供方向箭頭、暱稱與距離。可直接查看遠方好友。好友位置不受隊伍切換或退出影響；GPS 分享需要連線及定位權限。切到背景或離開網頁不會主動撤回；最後一次 GPS 位置保留 15 分鐘，2–15 分鐘標示「最後位置」與更新時間，超過 15 分鐘隱藏。以最後位置計算的方向使用較淡扇形與虛線光暈，並標示估算；圓形光暈是方向視覺，不表示實際 GPS 精度範圍，精度以文字呈現。只保存一筆座標，不記錄歷史軌跡。

地標左下卡片提供留言板，只有目前遠征隊成員可讀取、發布現場回報；每則最多 600 字，顯示最新 20 則，支援重試去重。留言不啟用 GPS；本人或目前隊長可刪除回報。地標移除或到期後停止隊內存取，作者仍可在個人檔案的留言管理查看並刪除自己的回報；既有評價和 XP 保留。回報本身不另計 XP。

「原地建立留言」入口已從地圖選單與情報點頁面移除。既有地面留言仍可閱讀、評價與刪除，沿用臨時地標的權限與到期規則。

目前地圖以幕張メッセ為預設場館，覆蓋經處理、約略對齊的場館圖。右上角場館選單可快速切換幕張、Kアリーナ横浜、ぴあアリーナMM、有明アリーナ；四個固定地標也能點選。已移除一公里開關、遮罩、邊界、相機範圍限制及按距離排除地圖標記的行為，台灣或其他地區皆可自由移動、縮放及標記。場館偏好仍保存在目前瀏覽器，切換場館不影響遠征隊資格；視窗大小變更保留地圖中心與比例。舊有範圍限制偏好不再使用。

未登入或未加入遠征隊也可使用本機定位。首次取得 GPS 後會移到實際所在地（包含台灣），並顯示「我的位置」。後續定位更新不會打斷使用者拖曳地圖；「回到我的位置」按鈕可再次移回所在地，沒有有效位置時會開啟定位設定。本機模式不上傳即時座標；其他模式在使用者主動同意後，依好友、目前小隊或任務接取權限提供位置。

首頁預設沒有自動加入遠征隊，必須選擇建立或加入隊伍才可發布任務。舊有遠征隊不會在更新時自動公開到場館列表。既有共享地標保留。

右上角「設定」提供黑夜模式開關，套用介面與地圖並記住此瀏覽器的選擇；未手動選擇前沿用系統外觀。未登入也可調整，登入後的帳號設定保留此選項。切換不重建地圖、不開啟 GPS，不影響地圖中心、縮放或尚未送出的表單與回報；Google 使用原生地圖樣式，備用地圖僅調整圖磚色調，頭貼和方向標記不反相。

## 遠征隊成員與管理

遠征隊頁面的「查看成員」及隊友列表，會在每位其他成員旁提供「⋯」選單。一般成員可申請好友或加入黑名單；團長另可指定／取消副團長、禁言／解除禁言與剔除成員；副團長可禁言及剔除一般成員，不能管理團長、其他副團長或自己。每次操作都會在交易內重新檢查權限。

禁言以遠征隊為範圍，限制該隊與所屬小隊聊天、任務發布、地標標記及地標留言；仍能閱讀、撤回自己的內容與退出。好友私訊不受遠征隊禁言影響。聊天輸入會顯示「已禁言」，伺服器也會拒絕繞過介面的發布請求。解除禁言即恢復發布資格。

黑名單以使用者為範圍，會移除彼此好友關係與邀請、拒絕雙向好友邀請及私訊，並阻止好友、小隊、求助及任務目標提供該人的位置。其他遠征隊成員仍可正常互動；共同隊伍的固定情報內容及群聊保留。可在「設定 → 黑名單」解除封鎖；原好友關係不會自動恢復。

每支已加入隊伍的「管理」選單都提供退出。團長另可解散、調整活動日期與可選開始時間（日本／台灣時區）、變更名稱、複製遠征隊、設定圖釘及更改隱私。解散前需明確確認。複製僅沿用名稱以外的會場、日期／時間、時區、隱私、加入密碼與圖釘設定；可自訂新名稱，建立新的隊伍 ID 及邀請碼，且只有建立者加入，不複製成員、小隊、任務、地標、聊天、定位或歷史紀錄。

加入方式可在公開、密碼及邀請之間切換。公開隊伍可由場館列表直接加入；密碼隊伍仍顯示在列表，但直接加入與邀請碼加入都必須提供密碼；邀請隊伍不顯示在場館列表，只接受邀請碼。設定只影響之後加入的使用者，既有成員保留。加入密碼使用 Argon2 雜湊，儲存在獨立設定表中，不回傳雜湊或明文。團長可以設定新密碼；保留密碼時留空。切離密碼模式會清除原密碼。

圖釘預設自由放置。改成審核放置後，一般成員提交的圖釘先保存在私有送審區，不出現在地圖或地標評價紀錄；只有本人、團長與副團長可查看。團長與副團長自己的圖釘直接放置。地標頁的「審核圖釘／我的送審圖釘」提供核准、拒絕或撤回；核准後才建立正式地標與評價紀錄。作者被禁言、停用或圖釘已過期時不能核准。退出／被剔除會自動清除該成員的待審圖釘。切回自由放置不會自動核准舊送審項目。

## News 公告

網站帳號管理放在右上角「設定 → 帳號管理」，只有既有 `momo` 帳號能查看註冊人數、分頁搜尋使用者，以及停用／恢復帳號。管理身分在資料庫升級時綁定該帳號的固定 ID，不因暱稱變更或其他人使用相同暱稱轉移。新資料庫需先建立 `momo` 帳號並重新啟動服務完成綁定。一般帳號不顯示入口，管理 API 亦拒絕存取。

停用會撤銷所有裝置的登入、拒絕再次登入並清除好友、小隊及求助的即時位置；在定位寫入交易內也重新檢查帳號狀態。帳號、遠征隊／小隊資格、地標、任務、聊天與評價資料保留。恢復後需重新登入並主動開啟位置分享，舊登入不會恢復；管理員不能停用自己。

手機下方導覽列提供「遠征隊」，可查看已加入隊伍，再進入場館列表加入或建立遠征隊；尚未登入時先引導登入。右上角提供「好友」預覽及「設定」捷徑；自己的私密小隊可從隊友頁面管理。News 移至自己的個人檔案工具列，提供「網站更新／活動公告」分類。帳號按鈕與 News 的提示點顯示新公告或待處理好友邀請，開啟閱讀後在目前瀏覽器記錄公告已讀；公告每分鐘及回到前景時重新檢查，也可關閉後再開啟取得最新內容。公告內容檔仍為公開資料。

登入後另有「好友邀請」分類，顯示自己的待處理邀請並提供接受／拒絕；邀請跟隨既有好友同步每 5 秒更新，開啟 News 時也會重新同步。待處理邀請的提示點持續保留至處理或取消。聊天訊息顯示發送者目前頭貼（無頭貼則顯示暱稱首字），點選他人的頭像可查看並送出好友邀請；已是好友、已送出或已收到邀請時顯示對應狀態。拒絕操作僅適用於本人收到且仍待處理的邀請，不會移除已接受的好友關係。接受不會自動開啟定位。私人邀請只從已登入的好友 API 讀取，不寫入公開公告檔或本機公告已讀紀錄，登出或切換帳號立即清除介面資料。

公告來源為 `static/news.json` 的 `announcements` 陣列，依 `published_at` 由新至舊顯示。新增公告時填寫唯一的 `id`、`type`（`update` 或 `event`）、`published_at`（`YYYY-MM-DD`）、`title` 及 `body`（純文字段落陣列）。活動可另加 `event_date`（`YYYY-MM-DD`）及 `link`（含 `url`、`label`，外部連結使用 HTTPS）。修改已發布公告時，更新 `updated_at` 時間字串可再次提示未讀。此檔為公開內容，請勿放入私人資訊；此版本從專案檔案維護公告。

## 執行與部署

```powershell
git clone https://github.com/IlikeBB/tamagoyaki-support.git
cd tamagoyaki-support
conda run -n agent python -m pip install -r requirements-tested.txt
conda run --no-capture-output -n agent python -m backend.server
```

本機網址為 `http://127.0.0.1:8078`。正式部署沿用 CozyPad 的本機服務＋Cloudflare Tunnel 方式，但使用獨立 Tunnel，不會重啟 CozyPad。

版本控制包含程式、靜態資源、測試與設定範例。`data/` 的帳號、訊息、頭貼與橫幅，以及金鑰、實際部署設定、執行日誌、備份和 `artifacts/` 測試產物保留於本機。

要使用 Cloudflare Tunnel，先複製 `scripts/cloudflare-public.example.json` 為 `scripts/cloudflare-public.json`，填入自己的 Tunnel ID 與網域，並備妥登入帳號下的 `.cloudflared` 憑證。範例檔不含可用憑證。

```powershell
# 首次登記 DNS；不會覆蓋既有同名記錄
powershell -NoProfile -File .\scripts\start-public.ps1 -RegisterDns
# 後續啟動會檢查並重用本專案程序
powershell -NoProfile -File .\scripts\start-public.ps1
# 僅停止經過身分驗證的本專案程序
powershell -NoProfile -File .\scripts\stop-public.ps1
```

Tunnel 憑證保存在使用者的 `.cloudflared`，不納入專案。設定在 `scripts/cloudflare-public.json`，日誌與程序資訊在 `.run-logs/`，資料庫在 `data/`。此部署依賴本機持續開機與連線，沒有設定開機自啟。修改 Python 後需停止本專案再啟動。備份 SQLite 時請停止本專案，或使用 SQLite backup API；不要只複製正在寫入的主資料庫檔。

環境變數：`TAMAGO_ORIGIN`（正式 HTTPS 來源，會啟用 Secure Cookie）、`TAMAGO_PORT`（預設 8078）、`TAMAGO_DB`（可指定獨立資料庫）。啟動腳本會設定正式來源。

## 定位與身分

- 定位預設關閉，只有使用者同意後才向瀏覽器請求定位。好友、目前小隊、目前遠征隊、任務接取者為互斥的即時分享模式，也可選擇僅供本機。小隊模式需先加入小隊，僅同遠征隊且同小隊的目前成員可取得座標；好友及其他遠征隊成員不會因此取得即時位置。離開或切換小隊會停止分享，延遲的舊小隊上傳也會被拒絕。一般任務接取者仍可取得明確發布的任務點，小隊外接取者不會取得小隊限定 GPS；求助持續沿用原本的全遠征隊廣播。
- 遠征隊模式需加入該隊，不必先發布任務。只有目前選定的隊伍成員能取得新鮮座標；分享給其他隊伍、改給好友或停止分享時，先清除原本的即時座標。離隊及位置過期後不再提供。完成任務不會中斷另行同意的遠征隊分享。
- 好友邀請需雙方接受。好友位置 API 與隊伍 API 分離，未接受的邀請沒有位置欄位；只有已接受的好友可取得對方主動分享且未過期的座標。拒絕、取消或移除關係立即撤銷存取。好友分享每次只保存最新座標，過期後於下一次每分鐘清理時刪除；停止分享、登出及改密碼也會清除。
- 開啟定位後可按資訊卡右側的「×」收起資訊卡，持續接收定位；按縮小後的「定位設定」可重新開啟設定。只有選擇「停止即時定位」才會停止定位，收起資訊卡不會擴大座標分享權限。
- 每 5 秒同步隊伍資料。只保存最後一筆座標，不記錄軌跡；2–15 分鐘未更新的座標標示為最後位置，超過 15 分鐘不對隊友顯示，並於下一次每分鐘清理時移除。讀取快照不會延長 GPS 有效期；同一筆 GPS 樣本不重複上傳。
- 任務發布點只回傳給發布者本人，以及進行中任務的目前接取者。其他成員不會從任務 API 取得發布點或任務距離；另行同意的遠征隊即時分享由成員位置提供。接取者完成、放棄，或任務撤回、到期後，不再提供任務發布點。
- 停止即時定位後，接取者仍能使用任務發布時的位置；撤回或結束任務可停止提供此座標。情報點是明確發布的隊內共享地點，不屬於隊員即時位置。
- 帳號名稱為 3–32 位英數字、底線、句點或連字號（開頭為英數字），不分大小寫；暱稱可使用中文。新密碼為 15–128 個字元，支援中文與空格，不會自動去除密碼前後空格。
- 密碼使用 Argon2id（19 MiB、2 次迭代、1 執行緒）與隨機 salt 雜湊；不儲存明文密碼。登入憑證為隨機 256-bit token，資料庫只存其 SHA-256，透過 HttpOnly、SameSite=Lax Cookie 保存 30 天，正式環境加上 Secure。
- 支援註冊、跨裝置登入、登出、修改暱稱與修改密碼。登出會在伺服器撤銷目前登入憑證並停止定位；修改密碼需驗證目前密碼，會撤銷其他裝置的登入並停止定位，目前裝置則換發登入憑證。
- 登入按來源 IP 與帳號分別限速，錯誤帳號與錯誤密碼使用相同訊息。密碼處理最多四個並行請求；超額回傳可重試的 429。驗證錯誤不回傳輸入的密碼。
- 帳號不會隨 30 天登入憑證到期而刪除。清除 Cookie 後可用帳號密碼重新登入並取回資料；舊訪客在原瀏覽器註冊會沿用原身分與資料歸屬。目前沒有電子郵件驗證、忘記密碼重設或帳號復原，請妥善保存帳號密碼。
- 公開遠征隊的名稱、日期與成員人數會出現在其場館列表；登入帳號可選擇加入。未公開的遠征隊只接受邀請碼。任務與情報點的內容只對成員開放；成員名單只提供主動開啟遠征隊分享且未過期的位置。
- 任務接取以 SQLite 交易避免重複接單。只有發布者或接取者可完成，只有發布者可撤回，只有接取者可放棄。
- 公開測試版採單一 Python 程序、SQLite。大型活動上線前應加入帳號復原、成員管理／封鎖／檢舉、負載測試與集中式速率限制。

## 網頁能力限制

方向浮標只顯示在本網頁內，不能跨其他 App 懸浮。手機指南針需裝置支援與授權；沒有絕對方位時北朝上。距離是直線距離，不是導航路線，室內 GPS 可能誤差很大。鎖屏、切到背景或斷網時無法保證 GPS 繼續更新；網頁維持 watchPosition，保留最後位置 15 分鐘，回到前景或 BFCache 恢復時立即請求新 GPS 並重新同步分享權限。暫時定位錯誤保留最後位置並重試；手動停止、登出、拒絕定位權限仍立即撤回。

可以加入手機主畫面；Service Worker 不快取私人 API 或地圖圖磚，不提供離線定位。

## 個人檔案、XP 與評價

點右上角帳號開啟個人檔案，可編輯暱稱、160 字簡介、頭貼與橫幅；好友、隊友與地標發布者的頭貼可開啟對方檔案。帳號設定仍從自己的檔案進入。JPG／PNG／WebP 照片限 12 MB，在瀏覽器以滑桿裁切成 320×320 頭貼或 1200×400 橫幅 PNG；伺服器驗證尺寸、CRC 與解壓縮長度，移除中繼資料，圖片僅提供給已登入者。照片確認裁切後立即儲存，文字另按儲存。

自己的個人檔案另有「地標管理」與「留言管理」：分開列出本人發布的地標與地面留言，包含仍存在的已到期內容，可分頁查看與確認後刪除。離開遠征隊後仍可刪除自己的內容；只有目前仍有成員資格且內容有效時可跳至地圖。管理 API 不回傳座標或邀請碼，只向目前登入者提供自己的內容，其他個人檔案不顯示管理控制。刪除使用交易重新檢查建立者，不移除評價封存與 XP；成功後立即清除目前地圖、列表與已選取的方向卡。已刪除或因負評移除的內容保留在原有評價紀錄，不會重新出現在管理清單。

遠征隊牆展示參加過的隊伍與場次，退出後保留紀錄，重新加入不重複計數。私人隊伍卡片只向本人與該隊目前成員顯示。啟用功能時補入仍在參加的隊伍與已建立的隊伍；此前已退出且未曾記錄的參加歷史無法還原。

自己的已退出或已解散場次提供「移除紀錄」，只移除自己的展示卡片及牆上計數；其他人的展示牆、遠征隊與地標評價各自保留。移除設定在重啟後持續生效，重新加入同一遠征隊時恢復展示。目前仍參加中的遠征隊需先退出，才能移除紀錄；此功能與隊長的「刪除遠征隊」分開。

遠征隊建立者可從「遠征隊 → 管理我建立的遠征隊」，或個人檔案的場次卡片刪除隊伍，退出後仍能管理。刪除需在介面確認，伺服器會在寫入交易內驗證建立者身分；清除該隊的任務、所有隊內地標、小隊、成員定位、求助定位及群聊，不影響其他遠征隊、好友分享或私訊。邀請碼立即失效。場次名稱、場館、日期與參加歷史另存為不含邀請碼的紀錄，個人檔案標示「遠征隊已刪除」，地標評價亦保留；私人場次仍依權限顯示。

進行中的任務提供「讚／倒讚」，限時與永久地標提供「有效／無效」評價，僅該遠征隊目前成員可操作，發布者不能評價自己。每人每則一票，可切換或再次點擊收回。任務評價不會額外授予座標權限；已完成、撤回或到期的任務不再接受新評價，持續中的求助沿用其有效期間。

個人檔案新增等級、稱號與 XP 進度。收到一個讚加 20 XP，倒讚扣 5 XP；以任務與地標目前保留的歷年評價合計，每 100 XP 升一級，最低 Lv.1。XP 可以為負數，進度條最低為 0；收回或切換評價會同步重算，可降級。等級與 XP 不能由修改個人檔案直接設定。任務結束、地標刪除或遠征隊解散後，評價與 XP 保留。既有地標評價自動納入，反覆提交同一票不會重複加分。

當無效票數嚴格大於有效票數時，會在同一筆投票交易中自動刪除限時地標或地面留言；平票保留，首張無效票亦適用。收回有效票後若變成無效票較多，也會移除。地標與評價封存紀錄仍保留，之後收回評價不會讓地標復原。啟動時會套用至既有符合條件的限時地標；永久地標與任務不會因負評自動移除。手動刪除仍限建立者或隊長。

個人檔案顯示收到的讚／倒讚總數、權限允許的任務與地標來源紀錄，以及僅本人可見的「我的評價」。退出後也能收回自己的歷史評價；封存資料不保存座標或描述。私人來源依隊伍成員權限過濾，總數包含歷年回饋。「累計限時標記」仍僅計算限時地標與地面留言，不計永久地標或任務。檔案與圖片不使用 Service Worker 快取，登出清空已載入的個人檔案。

## 好友私訊、遠征隊與小隊群聊

好友對話列表、私訊標題及訊息旁顯示個人檔案頭貼，未設定或載入失敗時以暱稱首字替代；群聊保留隊伍圖示，各發送者的訊息仍顯示自己的頭貼。好友更換或移除頭貼後，既有私訊中的頭貼會隨每 5 秒同步更新，不重建訊息或清空草稿。私訊標題與訊息頭貼均可開啟好友邀請資訊。

按上方訊息圖示開啟對話列表，可篩選好友、遠征隊與小隊，也可從好友的「聊天」按鈕或自己小隊的「小隊聊天」直接進入。建立或加入小隊後自動出現該小隊聊天室，並標示所屬遠征隊；只有目前同小隊的成員能讀寫，其他遠征隊成員無法查看。支援 2000 字以內的純文字、換行、表情、每 5 秒同步、未讀數與分頁載入歷史紀錄。Ctrl／⌘ + Enter 可傳送，Enter 保留換行；傳送失敗保留草稿，重試使用同一訊息識別碼以避免重複。

私訊只提供給已互相接受邀請的好友；群聊只提供給目前隊員，包含現有群聊紀錄。每次讀取、傳送與更新已讀游標都重新驗證身分與關係。移除好友或退出遠征隊後立即拒絕後續存取；重新建立關係後可查看原有紀錄。訊息保存於 SQLite，僅以純文字顯示，不附帶定位座標；聊天內容與草稿不放進 localStorage 或 Service Worker 快取。登出與切換帳號會清空頁面中的聊天狀態。未讀提示是網站內提示，不是背景系統推播。

離開或切換小隊後立即拒絕存取舊聊天室，同步時清空舊對話與草稿；重新加入仍存在的小隊後可查看原有紀錄。空小隊自動解散與遠征隊刪除時，一併清除所屬小隊的聊天及已讀紀錄。升級會以交易更新 SQLite 的聊天類型限制，保留既有訊息、訊息編號、已讀游標、重試去重約束與索引。

手機聊天視窗會單獨適應鍵盤高度，關閉鍵盤後回到完整 App 高度；不修改主畫面版的全螢幕高度計算。測試聊天寫入必須使用獨立 `QA_ORIGIN=http://127.0.0.1:8079`。

安裝後使用全螢幕顯示模式（不支援時使用 standalone），頁面依實際可見高度分配頂欄、地圖與底部導覽列，系統安全區只計算一次。介面固定 1 倍縮放；雙指縮放、雙擊或 ＋／－ 只改變地圖比例，介面外的雙指縮放與頁面縮放快捷操作會攔截。手機輸入欄至少 16px，避免 Safari 聚焦時自動放大。作業系統的輔助放大功能不屬於網站可控制範圍。

iPhone／iPad 主畫面模式（`navigator.standalone`）使用 `100vh` 作為完整 App 高度，CSS 載入前便設定，旋轉或返回時保持此規則，不把 `visualViewport.height` 寫成固定像素。WebKit 已記錄主畫面模式的可見高度少算安全區問題（[254868](https://bugs.webkit.org/show_bug.cgi?id=254868)）；一般瀏覽器與 Android 仍使用可見高度。回歸測試模擬少算 47px、縮放、鍵盤開關與旋轉，未取代 iOS 真機驗證。

## Google 地圖設定

將專案根目錄的 `google-maps.local.example.json` 複製為 `google-maps.local.json`，填入啟用 Maps JavaScript API 的瀏覽器金鑰：

```json
{"apiKey":"YOUR_GOOGLE_MAPS_API_KEY","language":"zh-TW","region":"JP"}
```

這個檔案已排除版本控制，也不會直接由網站提供下載。瀏覽器金鑰會透過不快取的 `/api/config` 傳給前端，因此必須在 Google Cloud 限制可用網站與 API。網站限制包含正式網址 `https://tamagoyaki-support.modoubletw.com/*`，以及開發使用的 `http://127.0.0.1:8078/*`、`http://localhost:8078/*`；API 限制選擇 Maps JavaScript API。此設定檔會在重新整理網站時讀取，不必重新啟動伺服器。

底圖使用官方 Maps JavaScript API，保留 Google 署名，幕張場館覆蓋圖沿用既有座標，地圖不設場館範圍限制。金鑰缺失時使用 OpenStreetMap；Google 連線或授權失敗時會顯示提示並切回 OpenStreetMap。隔離 QA 伺服器可設定 `TAMAGO_MAP_PROVIDER=leaflet`，避免使用正式金鑰或依賴外部地圖授權。

涵蓋建立／加入、成員預覽、日期區間、失敗重試、場館請求競態、帳號切換、搜尋與鍵盤焦點、CSP，以及手機／桌機與黑夜模式。聊天另驗證私訊／遠征隊／小隊權限、傳送重試去重、草稿與頭貼、歷史捲動位置、已讀、輸入法組字、禁言、離線與好友／小隊邀請。會註冊帳號或變更成員的測試僅可對隔離 QA 環境執行。

### 功能驗證

任務類型包含「聚餐」。選取「求助」時須先取得 GPS，發布後以紅色驚嘆號顯示發布者的即時位置，求助所在遠征隊的所有成員皆可查看，不必接取；不會擴及其他遠征隊或僅有好友關係的人。求助持續到發布者按「刪除求助」，沒有一般任務的到期時間；多個求助須刪除最後一個才停止持續定位。切換隊伍與重新整理會恢復求助定位；定位暫時失效時保留最後位置 15 分鐘並重試；2–15 分鐘標示最後位置，滿 15 分鐘未更新後隱藏。拒絕權限會立即撤回座標，須手動開啟，退出該隊或登出也會撤回位置。既有未同意廣播的舊任務不會因更新擴大位置權限。

帳號選單提供「全螢幕／加入主畫面」。支援 Fullscreen API 的瀏覽器可在點擊後進入全螢幕；iPhone／iPad 顯示 Safari 加入主畫面步驟，Android／電腦提供安裝引導與可用時的原生安裝提示。安裝後從主畫面啟動使用 `fullscreen`，不支援時回退至 `standalone`；已加入 iOS 網頁 App 設定與安全區留白。普通分頁不會自動強制全螢幕。服務工作者仍不快取私密 API 或地圖。參考 [MDN 安裝提示](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Trigger_install_prompt)、[顯示模式](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/display)、[Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen) 與 [Chrome 安裝網頁應用程式](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=zh-Hant)。

地圖左上角使用 Google Maps JavaScript Places Library 的 `Place.searchByText()`（Text Search New），可輸入地點名稱或地址，按「搜尋」後選取結果，再標記限時／永久地標或固定任務旗標。搜尋包含台灣與日本，選取結果後直接移至該地點。使用 `google-maps.local.json` 的同一把受網站限制金鑰，需啟用 Places API (New)（`places.googleapis.com`），並將該服務加入金鑰允許的 API；原本的 Maps JavaScript API 與網站限制保留。搜尋在瀏覽器直接送往 Google，不經 Python 代理，不再呼叫 Photon，也不使用原本的 24 小時伺服器搜尋快取。只在送出時查詢，僅要求地點 ID、名稱、地址、座標四個欄位，最多 8 筆；不附上使用者 GPS。搜尋結果保留在目前頁面記憶體，清空或離開後不保留，並顯示 Google Maps 與供應者標示。Google 搜尋不可用時會顯示錯誤，可重試或長按地圖標記；舊版 `/api/places/search` 回傳 410 提示重新整理。參考 [Text Search (New)](https://developers.google.com/maps/documentation/javascript/place-search)。

情報點頁面提供「臨時情報點」與「定期情報點」建立按鈕。臨時情報點預設 2 小時，可選 2、6、24 小時，到期後隱藏；定期情報點依需求代表永久保留、手動刪除，以 `hours: 0` 發布，`expires` 為 `null`。表單可切換保留方式，列表與方向卡會顯示對應類型。兩者皆可評價並計入 XP；定期情報點不因負評自動移除。只有建立者與目前遠征隊的建立者（管理員／隊長）可刪除，伺服器會檢查權限。長按地圖約 0.6 秒（電腦也可按右鍵）可選取情報點座標，搜尋地點後也可標記；從情報點頁面建立時預設使用地圖中心，可改用目前 GPS。任務旗標仍固定在選定位置，只有接取者能取得座標。方向卡顯示在地圖左下側，位於定位設定卡下方。
